# ISO/IEC 27001:2022: Annex A mapping

ISO/IEC 27001 certifies an **information security management system** (Clauses 4 to 10), not a toolchain.
This repository implements **technical controls that map to Annex A** and no management system: no management
review, internal audit programme, risk acceptance by top management, or supplier-contract lifecycle
([Scope §0.5](../00-scope.md)).

!!! info "About the wording"
    The standard is copyrighted and sold by ISO, so control *text* is not reproduced here. Control numbers and
    titles are listed; read the standard itself ([ISO page](https://www.iso.org/standard/27001)) for the requirement.
    This page is the Annex A applicability table that [Scope](../00-scope.md) refers to as
    `docs/02-statement-of-applicability.md` (that file was never written). It is **not** a formal Statement of Applicability, which an organisation
    must produce itself, with justification.

## Out of scope: the management system

Clauses 4 to 10 (context, leadership, planning, support, operation, performance evaluation, improvement) are
organisational. See [Limitations](../04-limitations.md).
