=== real bugs found and fixed getting here, not a clean first pass ===
- cert-manager's Helm chart defaults leader-election Role/RoleBinding creation to
  kube-system (legacy default) — the platform AppProject deliberately excludes that
  namespace (Phase 6). Fixed with global.leaderElection.namespace, pointed at
  cert-manager's own namespace instead of widening the AppProject.
- Grafana's chart extraVolumes only recognizes a fixed set of shorthand keys
  (existingClaim, hostPath, csi) and silently falls back to emptyDir for anything
  else — a plain `secret: {secretName: ...}` volume source produced an EMPTY mounted
  directory and a real crash loop ("cannot find SSL cert_file"), not an error at
  apply time. Confirmed the actual cause via `helm template` against the exact same
  values before attempting a fix, then confirmed the fix the same way before
  redeploying. The chart's dedicated extraSecretMounts key is what actually works.
- Switching Grafana's server.protocol to https breaks its default liveness/readiness
  probes (they don't parameterize scheme by protocol) — anticipated from a previous,
  different startup-probe failure on this same deployment, added scheme: HTTPS to all
  three probes (startup/readiness/liveness) up front rather than hitting a second
  crash loop to find it again.
