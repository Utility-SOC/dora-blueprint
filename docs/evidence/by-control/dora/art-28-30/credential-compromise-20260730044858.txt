=== Tetragon admission: confirmed via a real denial before the exception was added ===

Deploying apps/tetragon.yaml with no Kyverno exception in place produced a real denial from
the cluster's own built-in PSS baseline controller (not Kyverno):

  pods "tetragon-pf7vx" is forbidden: violates PodSecurity "baseline:latest": host
  namespaces (hostNetwork=true), hostPath volumes (volumes "cilium-run", "tetragon-run",
  "export-logs", "bpf-maps", "host-proc"), privileged (container "tetragon" must not set
  securityContext.privileged=true)

Fixed with the same dual mechanism velero's node-agent already established: a native PSS
namespace label (bootstrap/install.sh step 11/14) plus a Kyverno exclude scoped to
`tetragon-*` pods (infrastructure/kyverno/policies/require-pod-security-restricted.yaml).
See docs/exceptions/tetragon.md for the full reasoning.
